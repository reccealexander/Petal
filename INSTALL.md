# Install Petal

## 1. Copy the app to Applications

1. Open `Petal.dmg`.
2. Drag **Petal** onto the **Applications** folder shortcut beside it.

## 2. Open the app for the first time

Because Petal is distributed without Apple Developer signing or notarization, macOS Gatekeeper will block a normal double-click the first time you launch it.

1. Open your **Applications** folder.
2. Right-click (or Control-click) **Petal** and choose **Open**.
3. In the dialog that appears, click **Open** again.

You only need to do this once.

## If “Open” is still unavailable

1. Open **System Settings** and select **Privacy & Security**.
2. Scroll down to the **Security** section.
3. Next to the message that Petal was blocked, click **Open Anyway**.
4. Confirm that you want to open the app.

After the first successful launch, Petal will open normally with a regular double-click.
